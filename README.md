# Library Management System

This project is a Library Management System developed with C++ and Win32 API.

The application includes user management, book management, borrowing operations, and a graphical desktop interface.

## Features

- User login and registration
- Book management system
- Borrow and return books
- Admin / moderator support
- File-based database system
- Win32 graphical interface

## Technologies

- C++
- Win32 API
- Object-Oriented Programming (OOP)
- File Operations

## Purpose

This project was developed to improve C++ programming, object-oriented programming, and desktop application development skills.
